# Security

## Reporting a vulnerability

Please do not report suspected security vulnerabilities through public GitHub
issues or discussions.

Use GitHub's private vulnerability reporting for the affected repository where
available: open its **Security** tab, then choose **Report a vulnerability**.

If private reporting is unavailable, email
[contact@corfedo.ai](mailto:contact@corfedo.ai) with the subject
`Corfedo security report`.

Include the affected repository and version or commit, the potential impact,
and steps to reproduce. Remove credentials, tokens, and proprietary source code
from examples and logs.

## Supported releases

Corfedo is in active development. A repository-specific security policy takes
precedence over this default, including any version-specific support information.
