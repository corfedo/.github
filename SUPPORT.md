# Support

GitHub issues are primarily for reproducible bugs and concrete feature requests.
Open an issue in the affected project repository and include enough information
to reproduce the problem or understand the proposed outcome.

For questions, design discussions, and general help, email
[contact@corfedo.ai](mailto:contact@corfedo.ai). Public documentation and community
discussion channels will be linked from the [Corfedo profile](https://github.com/corfedo)
as they become available.

For security issues, follow the
[security policy](https://github.com/corfedo/.github/blob/main/SECURITY.md).
