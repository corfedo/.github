# Corfedo organization files

This repository contains the [public Corfedo profile](profile/README.md) and
organization-wide community defaults for repositories without their own:

- [Code of conduct](CODE_OF_CONDUCT.md)
- [Contribution guide](CONTRIBUTING.md)
- [Security policy](SECURITY.md)
- [Support guide](SUPPORT.md)
- [Issue forms](.github/ISSUE_TEMPLATE/) and a
  [pull request template](.github/PULL_REQUEST_TEMPLATE.md)

Repository-specific instructions take precedence over these defaults.

## Profile assets

The two SVGs in `profile/assets/` are unchanged copies of
`branding/logo-light.svg` and `branding/logo-dark.svg` from `corfedo-assets`,
the source of truth for Corfedo branding. Refresh the copies from that repository
when the approved artwork changes.

Each project repository maintains its own license. Licenses are not inherited
from this repository.
