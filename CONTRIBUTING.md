# Contributing to Corfedo

Thanks for contributing to Corfedo.

## Before opening a pull request

- Check existing issues and pull requests.
- Keep changes focused on one problem.
- For substantial behavioral or architectural changes, open an issue or
  discussion first.
- Follow the repository's local development and testing instructions.

## Pull requests

A pull request should explain:

- What changed and why.
- How the change was tested.
- Any compatibility or migration implications.

Repository-specific contribution instructions take precedence over this file.
Follow the [Corfedo code of conduct](https://github.com/corfedo/.github/blob/main/CODE_OF_CONDUCT.md)
when participating.

## Contributor License Agreement

Contributions covered by the [Corfedo Contributor License Agreement](https://gist.github.com/corfedo-ww/c7a7fd0138769a1050c1eae4c447e449)
require acceptance of the agreement before they can be merged. CLA Assistant
checks pull requests and provides a link to review and accept the current
agreement if your signature is required.

If an employer or another organization owns rights in your contribution,
obtain authorization to grant the rights described in the agreement before
submitting it. For questions about contribution authority, contact
[contact@corfedo.ai](mailto:contact@corfedo.ai).

## Reporting security issues

Do not report security vulnerabilities through public issues. Follow the
[security policy](https://github.com/corfedo/.github/blob/main/SECURITY.md).
